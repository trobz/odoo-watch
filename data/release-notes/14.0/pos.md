# PoS — Odoo 14.0

## Cash Rounding

Set a cash rounding in the PoS in the same way that accounting cash rounding works.

## Configuration

Modify the configuration of a PoS while a session is opened.

## Loyalty Programs

Improved usability of the loyalty programs.

## Mobile

Use PoS on mobile. Answer the growing demand for a mobile interface in stores.

## Payments

Handle several payment methods more easily, thanks to a clearer interface.

## Product Configurator

The product configurator is now available in Odoo PoS.
